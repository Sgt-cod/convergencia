Política de Privacidade

Última atualização: 04/09/2026

Este aplicativo é uma automação pessoal usada exclusivamente para publicar vídeos no canal do YouTube do próprio desenvolvedor/proprietário. Não coletamos, armazenamos, compartilhamos ou vendemos dados de terceiros.

Dados acessados

O aplicativo utiliza a API do YouTube (escopo youtube.upload) apenas para enviar vídeos ao canal autorizado pelo próprio usuário/proprietário da conta. Nenhum dado é compartilhado com terceiros ou usado para finalidades além do upload de conteúdo.

Armazenamento

As credenciais de acesso são armazenadas de forma criptografada como secrets em um pipeline de CI/CD privado e não são acessíveis publicamente.
